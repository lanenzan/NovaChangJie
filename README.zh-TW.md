# 星倉頡

[English](README.md)

星倉頡是一套免費的 Windows 10 及 11 倉頡輸入法，重現舊版「微軟新倉頡」的功能，並原生支援 Windows 11。

安裝程式會加入兩個鍵盤：**星倉頡**及**星速成**。

星倉頡是獨立項目，與微軟沒有任何關係。

> **狀態：** 早期版本，建議先在虛擬機器上試用。

## 功能

- **倉頡及速成：** 倉頡五代或三代（亦可兩者混打），另有獨立的速成鍵盤。
- **智慧選字：** 連續輸入整句，輸入法按前後文自動選字。按 ↓ 更改選字，按 Enter 送出。
- **越打越順手：** 常用的字詞會排在前面。
- **聯想詞：** 打完一個詞後，列出可能接着出現的詞語。
- **預測及萬用字元：** 列出字根開頭相同的字；忘記部分字根時可用 `*` 代替。
- **私隱：** 在密碼欄直接輸入英文，在瀏覽器的私密視窗打的字詞不會被記住。
- **輸出簡體中文：** 以倉頡輸入，送出簡體字。
- **使用者造詞：** 加入自己的詞語及速記碼。
- **符號及標點：** 中文標點、全形／半形及符號碼。
- **配合 Windows 11：** 跟隨淺色／深色主題，可在瀏覽器、市集應用程式、遊戲及登入畫面使用。

## 按鍵

| 按鍵 | 輸入字根時 | 其他時候 |
|---|---|---|
| a–z | 加入字根 | 開始輸入字根 |
| 空白鍵 | 送出反白的字 | 空白 |
| 1–9 | 選取候選字 | 數字 |
| Shift+1–9 | – | 選取聯想詞 |
| ↑ ↓ | 移動反白 | – |
| PgUp／PgDn | 換頁 | – |
| `*` | 萬用字元 | `*` |
| Enter | 把字母當作英文送出 | Enter |
| Esc | 取消 | – |
| Backspace | 刪除一個字根 | Backspace |
| 單按 Shift | 切換中／英 | 切換中／英 |
| Shift+空白鍵 | 切換全形／半形 | 切換全形／半形 |
| Ctrl+. | 切換中／英文標點 | 切換中／英文標點 |

## 安裝

1. 下載並執行 `NovaChangJie-0.9.2-x64.msi`。
2. 按 Win+空白鍵切換到**星倉頡**或**星速成**。

設定程式在開始功能表的「NovaChangJie Settings」。如要解除安裝，請到「設定 → 應用程式」。

## 從原始碼建置

安裝 Visual Studio 2022 及 Windows 11 SDK 後執行：

```powershell
.\tools\fetch-data.ps1 -Neural
.\build.ps1 -Msi
```
